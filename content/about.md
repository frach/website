I'm Filip, a DevOps and cloud engineer based in Poznań, Poland, with a Python development background. I've spent about ten years working with AWS, mostly in mature products where reliability, documentation and security matter, and I've also helped a startup build a hybrid cloud setup on a small budget.

## What I work with

- **Infrastructure as code:** Terraform and Terragrunt in multi-account, multi-region environments; CloudFormation
- **Kubernetes:** EKS, Helm, kubeflow, OpenShift, and IAM access for pods (IRSA, and later EKS Pod Identity)
- **CI/CD and automation:** Jenkins, GitHub Actions, Bitbucket and GitLab pipelines, Ansible, SaltStack
- **AWS services:** VPC and networking, ECS/Fargate, Lambda, API Gateway, DynamoDB, RDS, OpenSearch, Batch, IAM/KMS, CloudWatch and CloudTrail
- **Python:** scripting, CLI tools and serverless microservices (mostly API Gateway + Lambda)
- **Security and compliance:** remediating vulnerabilities and keeping build and deployment environments SOC 2 compliant

## Experience in short

- **Today:** the sole cloud engineer on a product team, owning the infrastructure, Terraform/Terragrunt code and deployment pipelines of a multi-region, multi-account product, in an environment kept SOC 2 compliant. I also document the whole setup, since documentation is part of keeping infrastructure maintainable.
- **Biotech startup (consultant):** helped move terabytes of daily computation from on-prem servers to a hybrid setup that was more flexible and cheaper, and built an EKS platform with kubeflow so bioengineers could run jobs at the best speed-to-cost ratio.
- **WorkFusion:** rewrote a VM-based product deployed with Ansible into a cloud-agnostic Kubernetes solution, and cut costs on the AWS CI/CD account.
- **F-Secure (2016-2020):** started as a software engineer building serverless microservices and near-real-time data processing, later led a team of DevOps engineers that took on AWS projects from requirements to documentation, including a rewrite around AWS Batch that significantly reduced costs. I was part of a 24/7 on-call rotation and ran hundreds of Elasticsearch and RabbitMQ instances.

## Teaching and knowledge sharing

I coached AWS workshops for external companies (2020-2024), and at F-Secure I started weekly AWS sessions that grew into a knowledge-sharing event with dozens of attendees, and ran multi-day AWS workshops in the Poznań and UK offices. I enjoy explaining how things work, which is why I write here.
